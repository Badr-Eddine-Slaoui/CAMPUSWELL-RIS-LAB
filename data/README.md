# Data Directory — CampusWell RiskLab

This directory contains all data artifacts used by the CampusWell RiskLab project.

## ⚠️ Important — Dataset Setup

The original dataset file is NOT included in the repository due to `.gitignore` rules.

You must place the dataset in the correct location before running any notebook or script.

### Step 1 — Download the Dataset

The dataset is sourced from Kaggle:

> **Mental Health Risk Prediction Dataset (Students)**
> https://www.kaggle.com/datasets/maqdadali/mental-health-risk-prediction-dataset-students

### Step 2 — Place the File

After downloading, place the CSV file here:

```
data/raw/student_mental_health_dataset.csv
```

The filename must exactly match the configured `DATA_PATH` in your `.env` file.

### Step 3 — Verify

You can verify the file is correctly placed by running:

```bash
python -c "from src.config import validate_config; ok, issues = validate_config(); print('OK' if ok else issues)"
```

---

## ⚠️ Ethical Notice

This dataset is **synthetic** and was generated for educational and portfolio purposes only. It does not represent real individuals. Any predictions produced by models trained on this data must **never** be used for clinical diagnosis, medical screening, disciplinary action, or any real-world decision-making about students' mental health.

## Data Quality Notes

The following columns contain realistic missing data:

| Column | Expected Missing % |
|---|---|
| `Financial_Stress` | ~4.5% |
| `Diet_Quality` | ~3.5% |
| `Sleep_Hours` | ~3.0% |
| `Social_Media_Hours` | ~3.0% |
| `Family_Support` | ~2.7% |
| `Attendance_Rate` | ~2.4% |
| `GPA` | ~1.9% |

**Age range note:** The dataset README documents ages 18–30. The actual dataset includes records with age 17. This discrepancy is documented in `ISSUES.md` and investigated during EDA. The age-17 records are retained unless analysis reveals them to be clearly invalid.
